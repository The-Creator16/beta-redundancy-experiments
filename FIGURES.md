# Figure index

Every figure is written as a high-DPI **PNG** (240 DPI) and an editable-text
**PDF** into `results/experiment_XX/paper_figures/`, using one consistent
colorblind-safe style (Okabe–Ito palette, one marker per system, shared legend
strips).

Legend for the **Role** column:

- **paper** — the exact panel used in the manuscript.
- **supplementary** — an additional diagnostic view generated by the same
  scripts but not printed in the paper (kept here for completeness and review).

System glyphs: `B` binary · `S` signed NAF · `Φ` golden ratio · `T₃` tribonacci ·
`T₄` tetranacci.
